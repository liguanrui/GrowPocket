## 2. 技术选型

| 类别 | 技术方案 |

## 4. 数据模型

### 4.1 数据模型定义

```mermaid
erDiagram
    Family ||--o{ Member : contains
    Family ||--o{ Task : has
    Family ||--o{ Reward : has
    Member ||--o{ Task : assigned_to
    Member ||--o{ PointsRecord : has
    Member ||--o{ ExchangeRecord : has
    Member ||--o{ Badge : earned
    Task ||--o{ TaskSubmission : has
    Reward ||--o{ ExchangeRecord : has

    Family {
        string id PK
        string name
        string avatar
        string invite_code
        timestamp created_at
    }

    Member {
        string id PK
        string family_id FK
        string nickname
        string avatar
        string role "parent|child"
        int current_points
        timestamp created_at
    }

    Task {
        string id PK
        string family_id FK
        string title
        string description
        int points
        string status "pending|in_progress|submitted|completed|expired"
        string assigned_to FK
        timestamp deadline
        timestamp created_at
    }

    TaskSubmission {
        string id PK
        string task_id FK
        string member_id FK
        string[] photos
        string note
        string review_status "pending|approved|rejected"
        int final_points
        timestamp submitted_at
    }

    PointsRecord {
        string id PK
        string member_id FK
        int change
        int balance_after
        string source
        string task_id FK
        timestamp created_at
    }

    Reward {
        string id PK
        string family_id FK
        string title
        string description
        string category "physical|experience|privilege"
        int points_required
        int stock
        string image
        timestamp created_at
    }

    ExchangeRecord {
        string id PK
        string reward_id FK
        string member_id FK
        int points_spent
        string status "pending|approved|rejected"
        string reject_reason
        timestamp created_at
    }

    Badge {
        string id PK
        string name
        string description
        string icon
        string criteria
    }
```

### 4.2 主要数据结构

#### 家庭表 (Family)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 家庭唯一标识 |
| name | string | 家庭名称 |
| avatar | string | 家庭头像URL |
| invite_code | string | 邀请码 |

#### 成员表 (Member)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 成员唯一标识 |
| family_id | string | 所属家庭ID |
| nickname | string | 昵称 |
| avatar | string | 头像URL |
| role | string | 角色：parent/child |
| current_points | number | 当前积分 |

#### 任务表 (Task)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 任务唯一标识 |
| family_id | string | 所属家庭ID |
| title | string | 任务名称 |
| description | string | 任务描述 |
| points | number | 积分奖励 |
| status | string | 状态 |
| assigned_to | string | 指派成员ID |
| deadline | timestamp | 截止时间 |

#### 奖励商品表 (Reward)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 商品唯一标识 |
| family_id | string | 所属家庭ID |
| title | string | 商品名称 |
| category | string | 分类 |
| points_required | number | 所需积分 |
| stock | number | 库存 |

## 5. 核心API接口（微信小程序端）

### 5.1 用户与家庭

| 接口 | 方法 | 说明 |
|------|------|------|
| /family/create | POST | 创建家庭 |
| /family/join | POST | 加入家庭 |
| /family/:id/members | GET | 获取家庭成员 |

### 5.2 任务管理

| 接口 | 方法 | 说明 |
|------|------|------|
| /tasks | GET | 获取任务列表 |
| /tasks | POST | 创建任务 |
| /tasks/:id/submit | POST | 提交任务成果 |
| /tasks/:id/review | POST | 验收任务 |

### 5.3 积分体系

| 接口 | 方法 | 说明 |
|------|------|------|
| /points/:memberId | GET | 获取积分余额 |
| /points/:memberId/records | GET | 获取积分明细 |
| /points/:memberId/curve | GET | 获取积分曲线数据 |

### 5.4 兑换商城

| 接口 | 方法 | 说明 |
|------|------|------|
| /rewards | GET | 获取商品列表 |
| /rewards/:id/exchange | POST | 申请兑换 |
| /exchanges | GET | 获取兑换记录 |
