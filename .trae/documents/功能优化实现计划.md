# 功能优化实现计划

## 一、项目调研结论

### 1.1 项目概述
项目名称：**童劳童得**，一个家庭亲子任务管理平台，通过任务和积分激励孩子养成良好习惯。

### 1.2 技术架构
- **前端**：React 18 + TypeScript + Vite + TailwindCSS + Zustand + React Router DOM
- **后端**：Go + Gorm + MySQL

### 1.3 核心模块分析

#### 首页 (`HomePage.tsx`)
- 当前功能：任务看板、积分卡片、孩子切换、任务状态筛选
- 待优化：视觉设计、数据展示、功能增强

#### 设置页 (`SettingsPage.tsx`)
- 当前功能：账户管理、家庭管理、勋章管理、任务模板管理
- 待优化：页面结构、勋章管理交互、功能完整性

#### 成就系统
- **后端**：`achievement_service.go` + `achievement.go` handler
- **前端**：`GrowthPage.tsx` + `growth.ts` service
- **问题识别**：
  - 勋章解锁需要手动触发，没有自动检查机制
  - 进度计算逻辑可能存在数据不一致
  - 自定义勋章创建时参数传递可能不完整

## 四、成就系统问题修复

### 4.1 勋章解锁不及时

#### 问题分析：
当前 `GetAchievements` 只返回现有状态，没有自动触发检查。勋章解锁需要手动调用 `checkAndUnlock` 接口。

#### 修复方案：
1. 在任务完成时自动调用勋章检查接口
2. 在获取勋章列表时自动触发检查逻辑
3. 优化后端检查逻辑，确保及时解锁

#### 修改文件：
- `backend/internal/service/achievement_service.go`：修改 `GetAchievements` 方法，自动触发检查
- `backend/internal/handler/achievement.go`：确保检查接口正确调用
- `frontend/src/services/growth.ts`：在获取勋章时自动调用检查
- `frontend/src/services/tasks.ts`：在任务提交/完成后调用检查

### 4.2 进度计算错误

#### 问题分析：
`calculateCurrentValue` 方法中：
- `AchievementTypeTotalPoints` 只计算 type=0 的交易，可能遗漏其他类型的收入
- `AchievementTypeConsecutiveDays` 的连续天数计算逻辑可能存在问题

#### 修复方案：
1. 修正积分计算逻辑，确保包含所有收入类型
2. 修复连续天数计算，处理日期边界情况
3. 添加单元测试验证计算逻辑

#### 修改文件：
- `backend/internal/service/achievement_service.go`：修复 `calculateCurrentValue` 方法
- `backend/internal/service/achievement_service_test.go`（新建）：添加测试用例

### 4.3 积分奖励异常

#### 问题分析：
`addAchievementPoints` 方法中查询孩子用户使用 `role = 'child'`，但数据库中角色存储值可能不匹配。

#### 修复方案：
1. 检查数据库中角色字段的实际存储值
2. 统一角色判断逻辑，使用常量定义
3. 确保积分奖励事务的原子性

#### 修改文件：
- `backend/internal/service/achievement_service.go`：修复角色判断逻辑
- `backend/internal/model/achievement.go`：添加角色常量定义

### 4.4 自定义勋章问题

#### 问题分析：
前端创建自定义勋章时调用 `growthService.createAchievement`，但传递的参数可能缺少 `family_id` 和 `created_by`。

#### 修复方案：
1. 前端创建勋章时传递完整参数
2. 后端验证参数完整性
3. 修复勋章列表查询逻辑，确保自定义勋章正确显示

#### 修改文件：
- `frontend/src/pages/SettingsPage.tsx`：修复勋章创建参数
- `frontend/src/services/growth.ts`：添加完整参数类型定义
- `backend/internal/service/achievement_service.go`：确保自定义勋章正确存储和查询
