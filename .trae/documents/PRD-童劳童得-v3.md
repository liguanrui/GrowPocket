# 童劳童得 PRD v3 - AI驱动的儿童能力成长陪伴平台

> **版本**：v3.0
> **更新日期**：2026-07-31
> **前置版本**：参考 `.trae/specs/tonglaotongde/spec.md`（v2，历史版本）
> **变更性质**：重大版本升级——从"任务-积分-兑换"工具型应用升级为"AI驱动的儿童能力成长陪伴平台"

---

## 1. 版本概述

### 1.1 版本定位

童劳童得 v3 从"任务-积分-兑换"的工具型应用，升级为"AI驱动的儿童能力成长陪伴平台"。在保留 v2 核心闭环的基础上，引入 AI 助理、能力维度系统、AI 任务生成、游戏化问卷四大模块，让产品从"家长手动管理任务"进化为"AI 基于儿童能力画像自动驱动成长"。

### 1.2 核心升级内容（四大模块）

| 模块 | 升级内容 | 价值 |
|------|----------|------|
| **AI 助理 Tab** | 新增 Tab，以"种子精灵"IP 形象为载体，通过对话完成查询/提交任务、查询积分、家长目标设置 | 降低使用门槛，提供陪伴感 |
| **能力维度系统** | 重构成长 Tab，用六大能力维度雷达图替换现有勋章系统，每个任务对应能力维度提升 | 从数量计数进化为能力评估 |
| **AI 任务生成** | 保留手动添加，新增 AI 每日自动创建任务（基于能力短板+家长目标） | 个性化驱动成长 |
| **游戏化问卷** | 设置 Tab 儿童信息收集改造为与 IP 交互的游戏化问卷，参考 MBTI 形式分阶段投放 | 持续完善儿童能力画像 |

### 1.3 与 v2 的差异说明

**保留（v2 不变的部分）**：
- 认证与授权机制（JWT，参考 v2 spec FR-001~FR-008）
- 家庭管理（参考 v2 spec FR-009~FR-014）
- 任务核心流程（创建→提交→验收，参考 v2 spec FR-015~FR-022）
- 积分流水体系（参考 v2 spec FR-023~FR-028）
- 商城兑换核心逻辑（扣分/扣库存，参考 v2 spec FR-029~FR-032，仅改变入口位置）
- 社区模块（动态/公益项目/公益活动，参考 community-module spec）

**变更**：
- Tab 结构调整：助手（新增）> 任务（原首页）> 成长（原成长+商城合并）> 社区（保留）> 设置（拓展）
- 成长模块：移除勋章系统，替换为能力维度系统
- 商城：从独立 Tab 降级为成长页内的兑换入口

**新增**：AI 助理、能力维度、AI 任务生成、游戏化问卷、IP 形象（种子精灵）

### 1.4 目标用户与非目标

**目标用户**（与 v2 一致）：
- 6-12 岁儿童的家长（尤其是多孩家庭）
- 家长为主要操作者，孩子可与家长一起操作

**非目标（v3 新增）**：
- **NG-v3-1**：不实现孩子独立登录的 AI 对话（MVP 阶段家长陪同下使用）
- **NG-v3-2**：不实现 IP 形象的 3D 化或 AR 呈现（2D 动画为主）
- **NG-v3-3**：不实现跨家庭的能力数据对比（聚焦单一家庭内成长）
- **NG-v3-4**：不实现 AI 语音对话（MVP 阶段仅文字对话）

## 2. IP 形象设计（种子精灵方向）

### 2.1 IP 角色定位

| 维度 | 说明 |
|------|------|
| **名称** | 小芽（候选：小芽 / 苗苗 / 豆豆，PRD 中暂用"小芽"） |
| **角色** | AI 助理的视觉载体，贯穿助手 Tab、设置问卷、成长回顾、任务标识 |
| **受众** | 6-12 岁儿童及其家长 |
| **性格** | 温暖、鼓励、好奇、有耐心、爱成长 |
| **核心隐喻** | 种子→发芽→小苗→小树→大树，象征儿童能力的成长进化 |

### 2.2 形象设定：种子精灵

**核心概念**：一颗会发芽的小种子/小树苗，呼应"成长"主题，随儿童能力维度总分提升而"长大进化"，形成可视化的成长激励。

**进化机制**：种子精灵的形态随儿童六大能力维度总分（0-600，每维度 0-100）变化，映射到 0-100 的成长指数后触发形态进化。

| 阶段 | 触发条件（成长指数） | 形态描述 | 能力动作 |
|------|----------------------|----------|----------|
| **阶段1：种子** | 0-20 | 一颗圆润的小种子，有两只小眼睛，躲在土壤里探头 | 眨眼、轻微晃动 |
| **阶段2：萌芽** | 20-40 | 种子裂开，长出两片嫩绿小叶，能挥手打招呼 | 挥手、点头 |
| **阶段3：小苗** | 40-60 | 茎干长高，叶子变多，能做出更多动作 | 思考、欢呼 |
| **阶段4：小树** | 60-80 | 长成小树苗，有树枝，能开花，表情更丰富 | 跳跃、拥抱 |
| **阶段5：大树** | 80-100 | 长成茁壮小树，能结出果实，象征丰收 | 庆祝舞蹈、闪光 |

**特殊形态**：完成阶段回顾后，精灵戴上"成长徽章"配饰（如小皇冠、小斗篷），记录里程碑成就。

### 2.3 视觉风格与表情系统

**视觉风格**（以用户指定参考图为准）：
- **风格参考**：[ip-reference-official.png](file:///Users/Admin1/Workhome/GrowPocket/.trae/documents/ip-reference-official.png)
  - 该图为 IP 形象的官方风格基准，所有进化阶段、表情、动作均需保持与此参考图一致的视觉风格
  - 后续实现时以此图作为视觉交付物的验收标准
- 进化时保持风格一致性，仅形态与配饰变化（参考 2.2 进化机制）

**表情系统**（至少 6 种基础表情，对话时根据语义切换）：
| 表情 | 触发场景 | 视觉描述 |
|------|----------|----------|
| 开心 | 任务完成、答题正确 | 眯眼微笑，叶子轻摆 |
| 鼓励 | 任务进行中、答题中 | 眼神坚定，竖大拇指 |
| 思考 | AI 处理中、查询中 | 歪头，头顶冒小问号 |
| 惊讶 | 新能力解锁、进化 | 睁大眼，嘴巴O型 |
| 安慰 | 任务失败、情绪低落 | 低头，叶子下垂 |
| 骄傲 | 阶段回顾、达成目标 | 挺胸，戴徽章闪光 |

**动作系统**：点头、挥手、跳跃、思考、拥抱、舞蹈等动作动画，配合表情使用。

### 2.4 IP 在各模块的呈现

| 模块 | IP 呈现方式 |
|------|-------------|
| **助手 Tab** | 作为对话窗口的头像，对话时有表情/动作变化；进入时精灵迎宾动画 |
| **设置问卷** | IP 作为"提问者"，引导儿童回答问题，答题时表情切换，完成时欢呼 |
| **成长回顾** | IP 作为"故事讲述者"，呈现成长故事，回顾时播放"进化"动画 |
| **任务页** | IP 在 AI 任务卡片上作为标识，任务完成时精灵庆祝动画 |
| **成长 Tab** | 能力维度雷达图旁展示当前精灵形态，直观反映成长阶段 |

### 2.5 IP 性格与对话风格设定

**对儿童**：
- 用简单易懂的语言，多鼓励，避免说教
- 自称"小芽"，用"我们一起..."的句式
- 语气示例："哇，你完成了洗碗任务！小芽觉得你的动手能力又变强啦~"

**对家长**：
- 提供专业建议，引用能力维度数据
- 切换为"成长顾问"语气
- 语气示例："根据小明近期的能力数据，独立自主能力提升了 8 分，建议下阶段侧重社交情感训练。"

### 3.1 研究依据

本能力维度系统综合参考以下青少年成长研究框架：

| 框架 | 来源 | 核心内容 | 借鉴点 |
|------|------|----------|--------|
| **中国学生发展核心素养** | 教育部 2016 | 3 维度（文化基础/自主发展/社会参与）6 素养 18 要点 | 本土化、与国内教育体系对齐 |
| **CASEL SEL 框架** | 美国社交情感学习组织 | 5 大社交情感能力（自我意识/自我管理/社交意识/关系技能/负责任决策） | 社交情感维度设计 |
| **Gardner 多元智能理论** | 哈佛大学心理学家 Gardner | 8 大智能（语言/逻辑数学/空间/身体运动/音乐/人际/内省/自然观察） | 多元能力视角 |

### 3.3 维度与任务的映射规则

**映射规则**：
- 每个 Task 关联 **1 个主能力维度** + **0-2 个次要维度**
- 任务难度（easy/medium/hard）对应能力提升权重：
  - easy = 1 分
  - medium = 2 分
  - hard = 3 分
- 任务完成后，主维度按权重累加，次维度按权重 × 0.5 累加
- 任务模板（TaskTemplate）需新增 `ability_dimension_id` 字段

**映射示例**：

| 任务 | 主维度 | 次要维度 | 难度 | 完成后能力提升 |
|------|--------|----------|------|----------------|
| 整理书包 | 生活自理 | 独立自主 | easy | 生活自理 +1，独立自主 +0.5 |
| 洗碗 | 动手实践 | 生活自理 | medium | 动手实践 +2，生活自理 +1 |
| 每日阅读 30 分钟 | 学习认知 | - | medium | 学习认知 +2 |
| 与同伴合作完成项目 | 社交情感 | 动手实践 | hard | 社交情感 +3，动手实践 +1.5 |
| 每日运动 30 分钟 | 身心健康 | - | medium | 身心健康 +2 |

### 3.4 能力评分与雷达图

**评分规则**：
- 每个维度分值范围：**0-100**
- 初始值由注册时的问卷测定（参考 4.5 问卷系统）
- 维度分值随任务完成动态更新（按 3.3 映射规则累加）
- 维度分值上限 100，达到上限后不再累加

**成长指数**（用于 IP 进化）：
- 成长指数 = 六大维度总分 ÷ 6（范围 0-100）
- 对应 IP 精灵的进化阶段（参考 2.2）

**雷达图展示**：
- 成长 Tab 首页展示六维能力雷达图
- 雷达图旁展示当前 IP 精灵形态
- 支持按时间维度对比（如本月 vs 上月）

**能力徽章**（替代旧勋章系统的轻量化成就）：
- 每个维度分值达到 30/60/90 时触发"能力徽章"
- 徽章分铜/银/金三档
- 徽章展示在成长页，可在社区分享

### 3.5 阶段目标与回顾机制

**阶段目标设置**：
- 家长通过 AI 助理设置周期阶段目标（如：4 周内提升"独立自主能力"10 分）
- 一个周期可设置 1-3 个维度目标
- 周期长度建议 2-4 周

**阶段回顾**：
- 阶段结束时家长触发"回顾"
- 回顾生成内容：
  1. **成长故事**（AI 生成）：基于周期内完成的任务、能力提升数据、成长相册
  2. **能力维度重新评估**：通过问卷重新测定（参考 4.5.3）
  3. **下周期目标建议**：AI 基于当前能力短板给出建议
- 回顾后进入下个周期，IP 精灵可能触发"进化"

## 4. 功能模块详述

### 4.1 助手 Tab（新增）

#### 4.1.1 功能定义

- **定位**：App 默认进入页，AI 助理以"小芽"IP 形象迎宾
- **交互方式**：对话式交互，支持自然语言输入
- **上下文感知**：自动填充当前儿童的基础信息、任务情况、成长回忆作为对话上下文
- **权限区分**：家长与儿童角色看到不同的对话风格与可操作范围

#### 4.1.2 对话上下文构造

System Prompt 由以下信息自动构造：

| 上下文模块 | 内容 |
|------------|------|
| **儿童基础信息** | 姓名、年龄（由生日计算）、性别、能力维度现状（六维分数） |
| **近期任务情况** | 待完成任务列表、进行中任务、本周已完成任务 |
| **成长回忆** | 近期完成的任务、能力提升记录、成长相册近期照片 |
| **当前阶段目标** | 家长设置的当前周期目标（维度+目标分值+剩余天数） |
| **角色权限** | 当前操作者是家长还是儿童 |

#### 4.1.3 支持的意图

| 意图 | 触发示例 | 动作 | 权限 |
|------|----------|------|------|
| 查询任务 | "我今天有什么任务？" | 返回今日任务列表 | 家长/儿童 |
| 提交任务 | "我完成了洗碗" | 调用任务提交 API | 家长/儿童 |
| 查询积分 | "我现在多少分？" | 返回积分余额 | 家长/儿童 |
| 查询能力 | "我的动手能力怎么样？" | 返回维度得分 + 雷达图 | 家长/儿童 |
| 查询精灵 | "小芽现在长什么样？" | 展示当前 IP 形态 | 家长/儿童 |
| 家长设置目标 | "给小明设定这周的目标" | 进入目标设置流程 | 仅家长 |
| 家长回顾 | "生成本月成长回顾" | 触发阶段回顾 | 仅家长 |
| 闲聊陪伴 | "我今天不开心" | IP 陪伴对话 | 家长/儿童 |

#### 4.1.4 IP 形象交互

- 对话窗口顶部展示 IP 头像（80x80）
- 对话时根据语义切换表情（参考 2.3 表情系统）
- 进入助手 Tab 时播放迎宾动画（IP 挥手 + 问候语）

- 在创建儿童档案时先录入基础信息，再进入问卷

#### 4.5.2 问卷维度映射规则

**题目设计规则**：
- 每道题目映射到 1 个能力维度
- 题目类型：
  - **情境选择题**（4 选 1）：每个选项对应不同分值（0-5 分）
  - **行为频率自评**（5 级量表）：从不(0)/偶尔(1)/有时(2)/经常(3)/总是(4)
- 计分规则：每个选项对应维度分值（0-5 分）

**初始能力维度分值计算**：
- 初始维度分值 = 该维度所有题目得分之和 ÷ 该维度题目数 × 20（映射到 0-100）
- 示例：独立自主能力 5 题，得分 3+4+2+3+4=16，分值 = 16 ÷ 5 × 20 = 64

**题目数量**：
- 每个维度 5-8 题
- 总计约 30-48 题（注册时仅答 6 题，其余分阶段投放）

#### 4.5.3 分阶段投放策略

| 阶段 | 时机 | 题目数量 | 目的 |
|------|------|----------|------|
| **注册时** | 创建儿童档案后 | 6 题（每维度 1 题） | 快速建立初始画像 |
| **每周** | 每周一 | 6 题（轮换维度） | 持续完善画像 |
| **阶段回顾时** | 回顾触发 | 12 题（每维度 2 题） | 重新评估能力维度 |

#### 4.5.4 游戏化交互设计

- **IP 形象作为"提问者"**：每题配有 IP 表情变化（参考 2.3）
- **答题进度以"探险地图"形式呈现**：每答一题解锁一个地图节点
- **完成问卷获得积分奖励**：注册问卷 +50 分，每周问卷 +20 分，回顾问卷 +30 分
- **题目以情境故事包装**：如"周末妈妈让你帮忙做饭，你会..."
- **答题反馈**：答完后 IP 精灵给出鼓励性反馈

## 6. 核心业务流程

### 6.1 AI 助理对话流程

```
用户输入 → 意图识别 → 权限校验 → 上下文构造 → 调用 LLM → 解析响应 → 执行动作 → 返回结果 → IP 表情切换
```

### 6.2 AI 每日任务生成流程

```
每日定时触发 → 读取儿童能力短板 → 读取家长阶段目标 → 读取历史任务偏好 → 调用 LLM 生成任务 → 写入 Task 表(ai_generated=true) → 推送家长审核
```

### 6.3 阶段回顾与成长故事生成流程

```
家长触发回顾 → 读取周期内任务/能力数据/相册 → 调用 LLM 生成成长故事 → 触发回顾问卷(12题) → 重新评估能力维度 → IP 进化判定 → 生成下周期目标建议 → 进入新周期
```

### 6.4 儿童信息问卷分阶段收集流程

```
触发时机(注册/每周/回顾) → 推送对应问卷 → IP 引导答题 → 探险地图进度 → 计算维度分值 → 更新 ChildAbilityScore → 发放积分奖励
```

### 6.5 能力维度评分更新流程

```
任务验收通过 → 读取任务主/次维度与难度 → 按映射规则计算分值 → 累加到 ChildAbilityScore → 判定能力徽章触发 → 判定 IP 进化 → 更新成长指数
```

## 7. 非功能需求

| 维度 | 要求 |
|------|------|
| **AI 响应时效** | 对话响应 < 3 秒，任务生成 < 10 秒，成长故事生成 < 30 秒 |
| **上下文长度** | 单次对话上下文不超过 4000 tokens，超出时截断早期历史 |
| **隐私保护** | 儿童真实姓名在对话中脱敏（显示昵称），数据不外泄给第三方 |
| **IP 形象一致性** | 所有模块中 IP 形象风格、色调、表情系统保持一致 |
| **数据安全** | AI 生成内容需经过滤，不适合儿童的内容拦截 |
| **离线可用** | 助手 Tab 离线时展示历史对话，任务/成长/社区/设置核心功能离线可用 |
| **性能** | 雷达图渲染 < 500ms，IP 动画流畅 60fps |
