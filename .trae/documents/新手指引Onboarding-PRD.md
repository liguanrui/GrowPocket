# 新手指引 Onboarding PRD

> 版本：V1.0 · 2026-08-01
> 状态：规划中（本阶段仅产出文档，不改代码）

## 1. 背景与目标

### 1.1 背景
当前注册成功后，用户被直接跳转至 `/settings/family`，看到一个简单的引导卡片 + 三字段表单（姓名/生日/性别），随后进入仅 6 题且不分龄的问卷。整个流程缺乏沉浸感，IP「小萌芽」未被充分利用，且无法根据儿童年龄/年级提供差异化评估。

### 1.2 目标
打造一条**强交互、游戏化**的新手指引流程：
- IP「小萌芽」全程陪伴，以对话式交互收集儿童信息（姓名、年龄、年级、爱好）
- 根据年级+年龄组合匹配 6 档分龄问卷，提供精准评估
- 问卷提前告知题数，每题进度提示，允许返回修改
- 完成后无缝进入主 App

### 1.3 核心指标
- 注册→问卷完成转化率 ≥ 80%
- 平均完成时长 ≤ 5 分钟
- 用户感知"有趣"（游戏化体验）

## 2. 用户流程图

```
注册成功
  ↓
/onboarding（独立路由，全屏流程）
  ↓
Step 1 欢迎页（IP 种子破土动画 + 自我介绍）
  ↓
Step 2 姓名收集（IP 提问 + 输入框）
  ↓
Step 3 年龄年级收集（年龄滑块 + 年级按钮）→ 决定问卷档位
  ↓
Step 4 爱好收集（多选标签）
  ↓
Step 5 问卷预告（告知题数 + 规则说明）
  ↓
/questionnaire?level=Lx&child_id=xxx（游戏化问卷页）
  ↓
问卷完成 → /growth（进入主 App 成长页）
```

### 2.1 关键跳转逻辑
- 注册成功：`RegisterPage.tsx` 由 `navigate('/settings/family')` 改为 `navigate('/onboarding')`
- Onboarding 完成信息收集后，调用后端创建儿童档案，获取 `child_id`
- 跳转问卷页携带 `level`（L1-L6）和 `child_id` 参数
- 问卷提交后跳 `/growth`

## 3. Onboarding 5 步设计

### 3.1 通用规范
- **全屏场景**：每步占据完整视口，无 BottomNav
- **顶部进度**：5 个圆点指示器，已完成填充暖橙 `#F59E6B`，当前放大+脉冲，未完成灰色
- **IP 位置**：屏幕中上部，尺寸 128x128，表情随步骤切换
- **背景**：暖橙奶油渐变 `#FFFAF4` → `#FFF1E6`
- **动画**：每步切换使用 `cardEnter`（translateY+scale），IP 使用 `animate-bounce`
- **返回**：左上角返回按钮，可回到上一步修改
- **按钮**：底部主按钮 `press-effect` 缩放反馈

### 3.2 Step 1：欢迎页

**场景**：IP 种子从土壤中破土而出的动画

| 元素 | 说明 |
|------|------|
| IP 形象 | seed 阶段（种子），expression=happy，animated |
| 动画 | 种子左右摇晃 → 破土 → 长出嫩芽（过渡到 sprout） |
| 主文案 | 「嗨！我是小萌芽 🌱」 |
| 副文案 | 「一颗会陪着你一起长大的小种子，很高兴认识你！」 |
| 主按钮 | 「开始我们的旅程」→ Step 2 |
| IP 表情 | happy → encourage |

**交互**：
- 进入时自动播放破土动画（约 2 秒）
- 按钮点击后 IP 切换 encourage 表情，过渡到下一步

### 3.3 Step 2：姓名收集

**场景**：IP 好奇地询问儿童姓名

| 元素 | 说明 |
|------|------|
| IP 形象 | sprout 阶段（萌芽），expression=think |
| IP 气泡 | 「你叫什么名字呀？」 |
| 输入框 | 大字号居中，placeholder「请输入你的名字」，暖橙聚焦边框 |
| 实时反馈 | 输入≥1字时 IP 切换 encourage，气泡变「{名字}，真好听！」 |
| 主按钮 | 「下一步」（输入非空才可点）→ Step 3 |
| IP 表情 | think → encourage（输入后） |

**交互**：
- 输入框聚焦时 IP 微微前倾
- 输入时 IP 表情实时切换，气泡文案动态更新
- 校验：姓名非空，≤20 字符

### 3.4 Step 3：年龄年级收集

**场景**：IP 询问年龄和年级，**此步决定问卷档位**

| 元素 | 说明 |
|------|------|
| IP 形象 | sprout 阶段，expression=think |
| IP 气泡 | 「你几岁啦？上几年级呢？」 |
| 年龄选择 | 滑块或数字按钮（6-12 岁），暖橙选中态 |
| 年级选择 | 6 个按钮横排（一/二/三/四/五/六年级），暖橙选中态 |
| 联动逻辑 | 选择年级后自动推荐年龄范围，允许手动调整 |
| 主按钮 | 「下一步」（两项都选才可点）→ Step 4 |
| IP 表情 | think → happy（选择后） |

**档位映射**（年级+年龄组合）：
| 选择 | 问卷档位 |
|------|---------|
| 一年级（6-7岁） | L1 |
| 二年级（7-8岁） | L2 |
| 三年级（8-9岁） | L3 |
| 四年级（9-10岁） | L4 |
| 五年级（10-11岁） | L5 |
| 六年级（11-12岁） | L6 |

> 若年级与年龄不匹配（如选六年级但年龄 6 岁），以**年级**为主匹配档位，并在后台记录 age 字段。

### 3.5 Step 4：爱好收集

**场景**：IP 拍手欢迎，询问兴趣爱好

| 元素 | 说明 |
|------|------|
| IP 形象 | sprout 阶段，expression=happy |
| IP 气泡 | 「你平时喜欢做什么呀？可以多选哦~」 |
| 爱好标签 | 网格布局，12 个可选标签 |
| 选中态 | 暖橙填充 + 白字 + 勾选图标 |
| 主按钮 | 「下一步」（至少选 1 个）→ Step 5 |
| IP 表情 | happy → proud（选择后） |

**爱好标签清单**（12 个）：
| 分类 | 标签 |
|------|------|
| 运动 | 跑步、球类、游泳、跳绳 |
| 艺术 | 绘画、音乐、手工、舞蹈 |
| 学习 | 阅读、拼搭积木、自然观察、棋类 |

> 爱好数据将影响后续 AI 任务生成偏好，存入 Child.hobbies 字段。

### 3.6 Step 5：问卷预告

**场景**：IP 介绍接下来的问卷，告知规则

| 元素 | 说明 |
|------|------|
| IP 形象 | sprout 阶段，expression=encourage |
| IP 气泡 | 「我还想多了解你一点点，这样能给你更适合的任务~」 |
| 信息卡片 | 三行说明：① 大概 {N} 题（根据档位动态显示）② 每题都有进度提示 ③ 可以随时返回修改答案 |
| 主按钮 | 「准备好了，开始！」→ 创建儿童档案 → 跳转问卷 |
| IP 表情 | encourage → proud |

**题数动态展示**：根据 Step 3 选定档位，显示该档题库题数（如 L1=16 题，L6=18 题）。

## 4. 问卷页增强设计

### 4.1 入口参数
```
/questionnaire?level=Lx&child_id=xxx&stage=register
```
后端根据 `level` 返回对应档位问卷。

### 4.2 问卷页 UI 增强

#### 4.2.1 顶部进度区（游戏化关卡路径）
- 替换现有普通进度条为**关卡节点路径**
- 每题一个节点（圆形），已答节点填充暖橙+勾选，当前节点放大脉冲，未答节点灰色
- 节点间用虚线连接，形成"探险地图"感
- 顶部文案：「第 X / N 题 · 进度 XX%」

#### 4.2.2 IP 提问者区
- IP 头像 48x48，表情随答题进度切换：
  - 第 1 题：think（思考）
  - 答题中：happy（开心）
  - 最后 1 题：proud（自豪）
- 气泡文案动态变化：
  - 第 1 题：「小萌芽想了解你~」
  - 答题中：「答得不错哦！继续~」
  - 最后 1 题：「就快完成啦，加油！」

#### 4.2.3 题目卡片
- 题干居中，大字号
- 选项按钮纵向排列，选中态暖橙边框+浅暖橙背景
- 选中后 IP 表情切换 encourage，0.5 秒后自动进入下一题（可配置手动确认）

#### 4.2.4 底部操作区
- 「上一题」按钮：允许返回修改，左侧
- 「下一题」/「完成」按钮：右侧，最后一题显示「完成评估」

#### 4.2.5 完成动效
- 提交后 IP 切换 bigtree + proud，播放成长动画
- 积分奖励提示「+50 积分」
- 1.5 秒后跳转 `/growth`

### 4.3 返回修改逻辑
- 点击「上一题」回到上一题，保留已选答案
- 修改答案后，重新计算该维度得分（覆盖式，非累加）
- 最后一题完成后提交，统一结算

## 5. 交互规范

### 5.1 色彩体系（暖橙奶油）
| Token | 色值 | 用途 |
|-------|------|------|
| `--gp-background` | `#FFFAF4` | 页面背景 |
| `--gp-primary` | `#F59E6B` | 主色（按钮/选中/进度） |
| `--gp-card` | `#FFFFFF` | 卡片背景 |
| `--gp-muted` | `#FFF1E6` | 次要背景（输入框/标签底） |
| `--gp-mutedFg` | `#7A7168` | 次要文字 |
| `--gp-border` | `#F5E6D3` | 边框 |

### 5.2 IP 表情联动规则
| 场景 | 表情 |
|------|------|
| 等待输入 | think |
| 输入中/选择中 | encourage |
| 完成输入/选择 | happy |
| 进入下一步 | proud |
| 最后一题/完成 | proud |
| 错误/空值提示 | comfort |

### 5.3 动画规范
| 动画 | 时长 | 用途 |
|------|------|------|
| `cardEnter` | 400ms | 步骤切换 |
| `animate-bounce` | 1s infinite | IP 待机 |
| `press-effect` | 150ms | 按钮按压 |
| `fadeIn` | 300ms | 气泡出现 |
| 破土动画 | 2s | Step 1 入场 |

### 5.4 可达性
- 所有按钮带 `aria-label`
- 输入框带 `label`
- 支持键盘 Tab 导航
- 颜色对比度满足 WCAG AA

### 6.3 问卷匹配逻辑

// 根据年级映射档位

    levelMap := map[int]string{1:"L1", 2:"L2", 3:"L3", 4:"L4", 5:"L5", 6:"L6"}

}

// 查询问卷时按 stage + level 过滤
