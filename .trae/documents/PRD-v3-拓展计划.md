### 3.2 核心内容详细设计

#### 3.2.1 IP 形象设计章节内容（种子精灵方向）

**IP 角色定位**：
- 名称：小芽（PRD中给出2-3个候选名：小芽/苗苗/豆豆）
- 角色：AI 助理的视觉载体，贯穿助手Tab、设置问卷、成长回顾
- 受众：6-12岁儿童及其家长
- 性格：温暖、鼓励、好奇、有耐心、爱成长

**形象设定：种子精灵**
- **核心概念**：一颗会发芽的小种子/小树苗，呼应"成长"主题，随儿童能力提升而"长大进化"
- **进化机制**：种子精灵的形态随儿童能力维度总分变化，形成可视化成长激励
  | 阶段 | 触发条件 | 形态描述 |
  |------|----------|----------|
  | 阶段1：种子 | 初始（总分0-20） | 一颗圆润的小种子，有两只小眼睛，躲在土壤里探头 |
  | 阶段2：萌芽 | 总分20-40 | 种子裂开，长出两片嫩绿小叶，能挥手打招呼 |
  | 阶段3：小苗 | 总分40-60 | 茎干长高，叶子变多，能做出更多动作（点头、思考） |
  | 阶段4：小树 | 总分60-80 | 长成小树苗，有树枝，能开花，表情更丰富 |
  | 阶段5：大树 | 总分80-100 | 长成茁壮小树，能结出果实，象征丰收 |
- **特殊形态**：完成阶段回顾后，精灵戴上"成长徽章"配饰，记录里程碑

**视觉风格与表情系统**：
- 主色调：嫩绿色（#7EC850）+ 暖阳橙（#FF9500，沿用品牌主色）
- 造型风格：圆润、柔和、Q版，无锐角，适合儿童审美
- 表情系统：至少6种基础表情（开心/鼓励/思考/惊讶/安慰/骄傲），对话时根据语义切换
- 动作系统：点头、挥手、跳跃、思考、拥抱等动作动画

**IP 应用场景**：
- 助手Tab：作为对话窗口的头像，对话时有表情/动作变化；进入时精灵迎宾动画
- 设置问卷：IP作为"提问者"，引导儿童回答问题，答题正确时精灵欢呼
- 成长回顾：IP作为"故事讲述者"，呈现成长故事，回顾时精灵"进化"动画
- 任务页：IP在AI任务卡片上作为标识，任务完成时精灵庆祝
- 成长Tab：能力维度雷达图旁展示当前精灵形态，直观反映成长阶段

**对话风格设定**：
- 对儿童：用简单易懂的语言，多鼓励，避免说教；自称"小芽"；用"我们一起..."的句式
- 对家长：提供专业建议，引用能力维度数据；切换为"成长顾问"语气
- 语气示例：
  - 儿童："哇，你完成了洗碗任务！小芽觉得你的动手能力又变强啦~"
  - 家长："根据小明近期的能力数据，独立自主能力提升了8分，建议下阶段侧重社交情感训练。"

#### 3.2.2 能力维度系统章节内容（核心）

**研究依据**（PRD中将明确列出综合的框架来源）：
- 中国学生发展核心素养（教育部2016）：3维度6素养18要点
- CASEL SEL框架：5大社交情感能力
- Gardner多元智能理论：8大智能维度
- 蒙台梭利生活技能：阶梯式生活自理能力
- 埃里克森心理社会发展：6-12岁"勤奋感 vs 自卑"

**六大能力维度定义**（PRD核心内容，每个维度含：定义、子能力、适龄表现、对应任务示例）：

| 维度 | 定义 | 子能力 | 研究来源 |
|------|------|--------|----------|
| **1. 生活自理能力** | 独立完成日常生活事务的能力 | 穿衣洗漱、整理收纳、简单烹饪、个人卫生 | 蒙台梭利 + 中国健康生活 |
| **2. 独立自主能力** | 自主决策、时间管理、承担责任的能力 | 自主决策、时间规划、责任意识、目标管理 | 埃里克森 + 中国学会学习 |
| **3. 动手实践能力** | 通过实际操作解决问题、创造产出的能力 | 家务劳动、手工制作、问题解决、工具使用 | Gardner身体运动+自然观察 + 中国实践创新 |
| **4. 学习认知能力** | 获取知识、思考探究的能力 | 学习习惯、阅读能力、逻辑思维、探究精神 | Gardner语言+逻辑数学 + 中国人文底蕴+科学精神 |
| **5. 社交情感能力** | 理解他人、管理情绪、建立关系的能力 | 情绪管理、同理共情、合作沟通、社交决策 | CASEL SEL + 中国责任担当 |
| **6. 身心健康能力** | 保持身体活力与心理韧性的能力 | 运动锻炼、健康习惯、心理韧性、安全意识 | 中国健康生活 + Gardner身体运动 |

**维度与任务的映射规则**：
- 每个 Task 关联 1 个主能力维度 + 0-2 个次要维度
- 任务难度（easy/medium/hard）对应能力提升权重（1/2/3分）
- 任务完成后，对应维度能力分值累加
- 任务模板（TaskTemplate）需新增 `ability_dimension` 字段

**能力评分与雷达图**：
- 每个维度分值范围：0-100（初始值由问卷测定）
- 成长Tab首页展示六维雷达图
- 维度分值随任务完成动态更新
- 分值达到阶段阈值触发"能力徽章"（替代旧勋章系统的轻量化成就）

**阶段目标与回顾机制**：
- 家长通过 AI 助理设置周期阶段目标（如：4周内提升"独立自主能力"10分）
- 阶段结束时家长触发"回顾"
- 回顾生成：成长故事（AI生成）+ 能力维度重新评估 + 下周期目标建议
