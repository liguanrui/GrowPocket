## Assumptions & Decisions

1. **绿色保留**：成长模块页头保持绿色渐变（`from-emerald-500 to-green-600`），不跟随 AI 助理模块的橙色系。UI 设计图需同步回退为绿色
2. **积分兑换页面**：增强现有 `MallPage.tsx` 而非新建页面，路由保持 `/mall`
3. **成长故事拆分**：新增列表页 `GrowthStoryListPage.tsx`，现有 `GrowthStoryPage.tsx` 保留为详情页
4. **雷达图实现**：从 recharts 改为原生 SVG，减少依赖但增加维护成本——这与设计图的静态展示需求一致
5. **底部导航**：设计图4Tab vs 现有5Tab，PRD 中记录差异但不强制调整（属于全局导航，超出成长模块范围）
6. **后端无变更**：所有 UI 调整均可通过现有 API 实现，无需后端改动
7. **GrowthStoryPage 页头颜色**：现有紫色渐变是否改为绿色统一，在 PRD 中列为可选项，由用户后续确认
